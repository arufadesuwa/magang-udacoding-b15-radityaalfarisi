# Laporan Minggu 1 — Divisi AI Engineer

## 1. Ringkasan Materi yang Dipelajari Minggu Ini

Pada minggu pertama ini, fokus pembelajaran adalah membangun fondasi *tools* kerja dan menguasai dasar-dasar bahasa pemrograman Python hingga konsep dasar OOP:

- **Setup Tools & Git/GitHub**: Instalasi dan konfigurasi Python, VS Code, Git, virtual environment, serta alur kerja Git (branching, commit konvensional, Pull Request, dan merge).
- **Python Dasar hingga Dasar OOP**: Mempelajari variabel, tipe data, *casting*, *f-string*, operator, percabangan (`if/elif/else`), perulangan (`for` & `while`), struktur data (`list`, `tuple`, `set`, `dictionary`, *list comprehension*), fungsi (default parameter, `*args`/`**kwargs`, `lambda`), manipulasi string, *exception handling* (`try/except/finally`), modul bawaan (`math`, `random`, `datetime`), serta dasar OOP (`class`, `__init__`, method, dan *inheritance* sederhana).
- **Penerapan ke Mini Project CLI**: Mengimplementasikan materi Python dasar dan OOP ke dalam aplikasi CLI **Pencatat Keuangan Harian** (`keuangan-cli`) lengkap dengan penyimpanan data persisten dan validasi input.
- **Pengenalan Dunia AI**: Memahami perbedaan AI, Machine Learning, Deep Learning, dan LLM, contoh penerapannya di Indonesia, perbedaan peran AI Engineer vs Data Scientist, serta menyusun peta belajar 3 bulan ke depan.
